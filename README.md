🌟 CV Interactivo & Portfolio Profesional - Gustavo Nicolás Samán

¡Bienvenido a mi repositorio de portfolio y CV interactivo! Una aplicación web moderna, dinámica y profesional diseñada para mostrar mi trayectoria, habilidades y proyectos como Desarrollador de Aplicaciones y Full Stack.

🚀 Acerca de la Web

Esta plataforma fue desarrollada desde cero como una Single Page Application (SPA) en React, priorizando una experiencia de usuario fluida, un diseño elegante tipo Dark Mode con efectos visuales avanzados (como un fondo interactivo tipo Matrix adaptado a la paleta de colores) y soporte multi-idioma en tiempo real (Español / Inglés).

✨ Características Principales

Soporte Multi-idioma (ES/EN): Cambio dinámico de idioma con un solo clic.

Fondo Interactivo Matrix: Animación personalizada en Canvas con alta legibilidad y optimización de rendimiento.

Diseño Responsive & Moderno: Interfaz adaptable a dispositivos móviles y de escritorio mediante Tailwind CSS.

Secciones Detalladas: Perfil profesional, experiencia laboral (TCI Chile y desarrollo autónomo), educación universitaria (UTN FRT), capacitaciones y habilidades técnicas organizadas por categoría.

Datos de Contacto Directos: Enlaces rápidos a GitHub, correo electrónico y teléfono.
